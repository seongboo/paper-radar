읽을 논문 PDF를 여기에 끌어다 놓으세요

파일은 이 컴퓨터에서 바로 열립니다. AI에 물을 때만 해당 내용이 설정에서 고른 AI 회사로 전송됩니다. 먼저 오른쪽 위 AI 설정에서 API 키를 넣으세요.

arXiv 논문
위쪽 칸에 arXiv 번호(예: 2408.12345)나 주소를 넣고 arXiv 열기를 누르면 내려받지 않고 바로 엽니다.
글자 선택
문장이나 수식을 끌어서 선택하면 설명, 번역, 유도, 참고문헌 버튼이 뜹니다.
옛날 논문
스캔본처럼 글자가 잡히지 않는 PDF는 상단의 글자 인식으로 AI가 쪽 단위로 읽습니다.
영역 캡처
그림, 표, 글자가 깨지는 수식은 상단의 영역 캡처로 잡아서 묻습니다.
대화
논문 전체를 맥락으로 질문합니다. 답변의 p.3 같은 표시를 누르면 그 쪽으로 이동합니다.
요약
방법, 결과, 기여, 가정과 근사를 정리하고 핵심 문장을 본문에 색으로 표시합니다.
메모
답변을 논문별 메모로 저장하고 Markdown으로 복사합니다.

논문을 열면 아래 질문으로 바로 시작할 수 있습니다.

요약은 풀려는 문제, 방법, 주요 결과, 기여, 가정과 근사, 한계 순서로 정리합니다. 핵심 문장 표시는 본문에서 해당 문장을 찾아 색으로 칠합니다.

방법 결과 기여

    본문에서 인용 번호(예: [12], 3–5)나 저자 표기를 선택한 뒤 참고문헌 버튼을 누르면 여기에 표시됩니다.

    AI 설정

    이 도구는 각자의 API 키로 동작합니다. ChatGPT나 Gemini 구독과는 별개이며, API는 쓴 만큼 과금됩니다. 키는 이 브라우저에만 저장되고 고른 AI 회사로만 전송됩니다.

    그림과 수식 캡처, 글자 인식을 쓰려면 이미지 입력을 지원하는 모델을 고르세요.
