# 논문 리더 (API 키 버전)

논문 PDF를 열고 옆에서 AI에게 묻는 읽기 도구입니다. 설치 없이 브라우저에서 동작합니다.

주소: https://seongboo.github.io/paper-radar/

## 기능

- arXiv 번호로 바로 열기: 위쪽 칸에 번호를 넣거나 주소 뒤에 `?arxiv=2408.12345`를 붙입니다
- 본문 선택 → 설명, 번역, 유도(중간 단계와 가정·근사 표시), 참고문헌 조회
- 영역 캡처 → 그림, 표, 수식을 이미지로 질문
- 논문 전체를 맥락으로 대화 (답변의 p.3 표시를 누르면 해당 쪽으로 이동)
- 요약, 핵심 문장 표시
- 스캔본 글자 인식
- 메모 저장과 Markdown 복사, 자주 쓰는 질문 저장

## 사용 전 준비

각자의 API 키가 필요합니다. ChatGPT나 Gemini 구독과는 별개이며 쓴 만큼 과금됩니다.

1. 오른쪽 위 **AI 설정**을 엽니다.
2. AI 회사(OpenAI, Google Gemini, Anthropic)를 고르고 API 키를 붙여 넣습니다.
3. **모델 목록 불러오기**를 눌러 모델을 고릅니다. 캡처와 글자 인식에는 이미지 입력을 지원하는 모델이 필요합니다.
4. **연결 확인**을 누른 뒤 저장합니다.

## 개인정보

- PDF는 브라우저 안에서만 열립니다.
- AI에 물을 때 해당 내용이 고른 AI 회사로 직접 전송됩니다. 중간 서버는 없습니다.
- API 키, 메모, 글자 인식 결과는 이 브라우저에만 저장됩니다. 공용 컴퓨터에서는 키 저장을 끄세요.

## 어떤 버전을 써야 하나

| 사용자 | 쓸 버전 |
|---|---|
| Claude 구독자 | Claude 안에서 만든 논문 리더(구독으로 동작, 키 불필요). 이 버전은 필요 없습니다 |
| 그 외 | 이 버전. API 키가 필요합니다 |

## 같은 저장소의 다른 도구

`main` 브랜치에는 **논문 레이더**(arXiv 신규 논문을 수집·요약·랭킹해 매일 다이제스트로 정리하는 Python 도구)가 있습니다. 레이더로 찾고, 리더로 읽는 구성입니다.

## 상태

- 세 회사(OpenAI, Gemini, Anthropic)의 요청 형식은 모의 서버로 점검했습니다.
- 실제 API 키를 사용한 호출은 아직 검증되지 않았습니다. 문제가 있으면 이 저장소의 Issues에 남겨 주세요.
